Power BI 看板制作指南

淘宝笔记本电脑市场分析 · 交互式看板从零搭建
预计用时 2-3 小时 含软件安装 7 个步骤
STEP 1

下载安装 Power BI Desktop

预计用时：10 分钟

  1. 打开浏览器访问：https://powerbi.microsoft.com/zh-cn/desktop/
  2. 点击「免费下载」
  3. 下载后双击 PBIDesktopSetup.exe 安装，全部默认下一步
  4. 安装完成后打开 Power BI Desktop，弹出登录窗口点「取消」跳过（不需要登录也能用）
STEP 2

导入数据

预计用时：5 分钟。已为你生成两个 Power BI 专用数据文件：

文件位置用途
powerbi_data.csvdata/powerbi_data.csv主数据（9列：标题、价格、价格区间、品牌、笔记本类型、省份、城市、销量、店铺）
word_freq.csvdata/word_freq.csv词云专用（已用 jieba 分词 + 停用词过滤，Top150 词频）

导入步骤

  1. 打开 Power BI Desktop
  2. 点击顶部菜单「主页」→「获取数据」→「文本/CSV」
  3. 选择 D:\taobao-laptop-analysis\data\powerbi_data.csv
  4. 预览窗口能看到数据，点「加载」
  5. 再次「获取数据」→「文本/CSV」→ 选择 word_freq.csv →「加载」

检查数据

导入后，在右侧「数据」面板应能看到两个表：powerbi_data（9列）和 word_freq（2列：词语、频次）

STEP 3

数据类型设置

预计用时：3 分钟。导入后需要确认字段类型正确：

  1. 点击左侧第三个图标「数据视图」（表格图标）
  2. 选中 powerbi_data 表
  3. 点击「价格」列 → 顶部菜单「列工具」→「数据类型」→ 选「固定十进制数」
  4. 点击「销量」列 → 同上设为「整数十进制数」
  5. 检查「价格区间」「品牌」「笔记本类型」应为「文本」类型
STEP 4

创建看板（核心）

预计用时：约 1 小时。点击左侧第二个图标回到「报表视图」（柱状图图标），开始逐个创建图表。

图表 1：KPI 卡片 × 4（顶部指标行）

卡片字段聚合方式格式
商品总数标题计数字号 24pt，标签「商品总数」
总销量销量求和字号 24pt，千位分隔符
平均价格价格平均值字号 24pt，货币 ¥ 格式
品牌数量品牌计数(不重复)字号 24pt

操作：点空白画布 → 右侧「可视化」面板点「卡片」图标 → 把字段拖到「字段」框 → 点字段右边下拉箭头改聚合方式 → 在「格式」里设置字号和标签

图表 2：价格区间商品数量（柱状图）

配置项字段
X 轴价格区间
Y 轴（值）标题 → 计数

排序：点图表右上角「...」→「排序依据」→ 选「价格区间」→ 升序。格式：数据标签打开，标题「价格区间商品数量」

图表 3：价格区间销量分布（柱状图）

配置项字段
X 轴价格区间
Y 轴（值）销量 → 求和

排序：按价格区间升序。格式：数据标签打开，柱形颜色改为绿色系

图表 4：笔记本类型销量分布（饼图）

配置项字段
图例笔记本类型
值销量 → 求和

格式：详细信息标签选「百分比」，标题「笔记本类型销量分布」。想做成环形图：格式里打开「圆环图半径」→ 设为 40%

图表 5：品牌销量 Top15（条形图）

配置项字段
Y 轴品牌
X 轴（值）销量 → 求和

只显示 Top15：把 品牌 拖到筛选器区域 → 选「前 N 个」→「顶部」→「15」→ 按 销量 的「求和」

图表 6：产地销量 Top10（条形图）

配置项字段
Y 轴城市
X 轴（值）销量 → 求和

处理「未知」城市：把 城市 拖到筛选器 →「高级筛选」→ 取消勾选「未知」。再设「前 N 个」→「顶部」→「10」

图表 7：商品标题词云（需安装自定义视觉对象）

安装词云插件

Power BI 默认没有词云：在可视化面板点「...」→「获取更多视觉对象」→ 搜索 Word Cloud → 点「添加」

配置项字段（来自 word_freq 表）
Category（类别）词语
Values（值）频次

格式：最大词数设为 100，旋转文字关闭，字体改为「微软雅黑」

STEP 5

添加切片器实现联动

预计用时：10 分钟。切片器是 Power BI 看板最大的亮点——点一个筛选条件，所有图表自动联动。

切片器字段格式建议
价格区间价格区间标题「价格区间筛选」
品牌品牌样式选「下拉菜单」，标题「品牌筛选」
笔记本类型笔记本类型标题「类型筛选」

验证联动

点切片器选「联想」→ 看板上所有图表自动只显示联想数据 → 再点「游戏本」→ 所有图表进一步过滤。这就是交互式看板的核心价值。

常见问题

词云不显示中文？
在词云格式设置里找到「字体」，改成「微软雅黑」或「SimHei」
饼图显示太多「其他类型」？
在筛选器里把 笔记本类型 的「其他类型」取消勾选，只保留游戏本/轻薄本/二合一
条形图排序不对？
点图表右上角的「...」→「排序依据」→ 选你要排序的字段 → 再点切换升序/降序
切片器选了之后图表变空白？
说明该筛选条件下没有数据，正常现象。点切片器右上角的「清除选择」橡皮擦图标恢复
价格区间排序是乱的？
在「数据视图」里给「价格区间」列设置「按列排序」→ 选一个排序列。或在 Power Query 里手动设置排序顺序
