# Power BI 看板制作指南

> 从零开始，手把手搭建「淘宝笔记本电脑市场分析看板」
> 预计用时：2-3 小时（含软件安装）

---

## 第一步：下载安装 Power BI Desktop（10 分钟）

1. 打开浏览器，访问：https://powerbi.microsoft.com/zh-cn/desktop/
2. 点击「免费下载」
3. 下载后双击 `PBIDesktopSetup.exe` 安装
4. 安装时全部默认下一步即可
5. 安装完成后打开 Power BI Desktop，弹出登录窗口点「取消」跳过（不需要登录也能用）

---

## 第二步：导入数据（5 分钟）

我已经帮你生成了两个 Power BI 专用数据文件：

| 文件 | 位置 | 用途 |
|---|---|---|
| `powerbi_data.csv` | `data/powerbi_data.csv` | 主数据（含价格区间、品牌、类型） |
| `word_freq.csv` | `data/word_freq.csv` | 词云专用（已分词+统计词频） |

### 导入步骤

1. 打开 Power BI Desktop
2. 点击顶部菜单「主页」→「获取数据」→「文本/CSV」
3. 选择 `D:\taobao-laptop-analysis\data\powerbi_data.csv`
4. 预览窗口里能看到数据，点「加载」
5. 再次「获取数据」→「文本/CSV」→ 选择 `word_freq.csv` →「加载」

### 检查数据

导入后，在右侧「数据」面板应能看到两个表：
- `powerbi_data`：9 列（标题、价格、价格区间、品牌、笔记本类型、省份、城市、销量、店铺）
- `word_freq`：2 列（词语、频次）

---

## 第三步：数据类型设置（3 分钟）

导入后需要确认字段类型正确：

1. 点击左侧第三个图标「数据视图」（表格图标）
2. 选中 `powerbi_data` 表
3. 点击「价格」列 → 顶部菜单「列工具」→「数据类型」→ 选「固定十进制数」
4. 点击「销量」列 → 同上设为「整数十进制数」
5. 检查「价格区间」「品牌」「笔记本类型」应为「文本」类型

---

## 第四步：创建看板（核心，约 1 小时）

点击左侧第二个图标回到「报表视图」（柱状图图标），开始逐个创建图表。

---

### 图表 1：KPI 卡片 × 4（顶部指标行）

#### 卡片 1：商品总数

1. 点击空白画布
2. 在右侧「可视化」面板点「卡片」图标（一个带数字的方框）
3. 把 `标题` 字段拖到卡片设置里的「字段」框
4. 默认显示计数，即商品总数
5. 在「格式」里设置：字号 24pt，标签文字「商品总数」

#### 卡片 2：总销量

1. 同样新建一个卡片
2. 把 `销量` 拖到「字段」
3. 默认是求和，即总销量
4. 格式里设：字号 24pt，标签「总销量」，数字格式选「千位分隔符」

#### 卡片 3：平均价格

1. 新建卡片
2. 把 `价格` 拖到「字段」
3. 点字段右边的下拉箭头 → 改为「平均值」
4. 格式：字号 24pt，标签「平均价格」，数字格式选「货币 ¥」

#### 卡片 4：品牌数量

1. 新建卡片
2. 把 `品牌` 拖到「字段」
3. 点字段右边下拉箭头 → 改为「计数 (不重复)」
4. 格式：字号 24pt，标签「品牌数量」

> 把 4 个卡片并排放在看板顶部

---

### 图表 2：价格区间商品数量（柱状图）

1. 点击空白画布
2. 在可视化面板点「簇状柱形图」
3. 字段配置：
   - **Y 轴**（X 轴）：拖入 `价格区间`
   - **Y 轴**（值）：拖入 `标题`，改为「计数」
4. 排序：点图表右上角「...」→「排序依据」→ 选「价格区间」→ 再点一次切换为升序
5. 格式设置：
   - 「数据标签」→ 打开
   - 「标题」→ 文字改为「价格区间商品数量」，字号 12pt
   - 「X 轴标签」→ 倾斜 30 度（如果文字太挤）

---

### 图表 3：价格区间销量分布（柱状图）

1. 新建簇状柱形图
2. 字段配置：
   - **X 轴**：`价格区间`
   - **Y 轴**：`销量`（求和）
3. 排序：按价格区间升序
4. 格式：
   - 数据标签 → 打开
   - 标题 →「价格区间销量分布」
   - 柱形颜色 → 改为绿色系（区分于上一个图）

---

### 图表 4：笔记本类型销量分布（饼图/环形图）

1. 在可视化面板点「饼图」
2. 字段配置：
   - **图例**：`笔记本类型`
   - **值**：`销量`（求和）
3. 格式：
   - 「详细信息标签」→ 选「百分比」
   - 标题 →「笔记本类型销量分布」
   - 图例位置 →「右」或「底部」

> 如果想做成环形图：在格式里找到「饼图」→ 打开「圆环图半径」→ 设为 40%

---

### 图表 5：品牌销量 Top15（条形图）

1. 在可视化面板点「簇状条形图」（横向条形图）
2. 字段配置：
   - **Y 轴**：`品牌`
   - **X 轴**：`销量`（求和）
3. 只显示 Top15：
   - 把 `品牌` 拖到可视化面板下方的「筛选器」区域的「此页上的筛选器」
   - 点开筛选器 → 选「前 N 个」→「顶部」→「15」→ 按 `销量` 的「求和」
4. 排序：点图表排序按钮，按销量降序
5. 格式：
   - 数据标签 → 打开
   - 标题 →「品牌销量 Top15」

---

### 图表 6：产地销量 Top10（条形图）

1. 新建簇状条形图
2. 字段配置：
   - **Y 轴**：`城市`
   - **X 轴**：`销量`（求和）
3. 处理「未知」城市：
   - 把 `城市` 拖到筛选器 →「高级筛选」→ 取消勾选「未知」
4. 只显示 Top10：
   - 筛选器设「前 N 个」→「顶部」→「10」→ 按 `销量` 的「求和」
5. 格式：
   - 数据标签 → 打开
   - 标题 →「产地销量 Top10」

---

### 图表 7：商品标题词云（需安装自定义视觉对象）

Power BI 默认没有词云，需要安装插件：

#### 安装词云视觉对象

1. 在可视化面板点「...」→「获取更多视觉对象」
2. 搜索框输入 `Word Cloud`
3. 找到「Word Cloud」（作者 Microsoft）→ 点「添加」
4. 添加成功后可视化面板会多出一个词云图标

#### 创建词云

1. 点击词云图标，在画布上画一个大方框
2. 字段配置：
   - **Category**（类别）：从 `word_freq` 表拖入 `词语`
   - **Values**（值）：从 `word_freq` 表拖入 `频次`
3. 格式设置：
   - 「Word Cloud」格式面板里：
     - 最大词数 → 设为 100
     - 旋转文字 → 关闭（横向更易读）
     - 颜色 → 选「分类着色」或固定一个色系
   - 标题 →「消费者关注热点词云」

---

## 第五步：添加切片器（筛选器）实现联动（10 分钟）

切片器是 Power BI 看板最大的亮点——点一个筛选条件，所有图表自动联动。

### 切片器 1：价格区间

1. 在可视化面板点「切片器」
2. 把 `价格区间` 拖入「字段」
3. 格式：标题改为「价格区间筛选」

### 切片器 2：品牌

1. 新建切片器
2. 字段：`品牌`
3. 格式：
   - 切片器样式 →「下拉菜单」（比列表省空间）
   - 标题 →「品牌筛选」

### 切片器 3：笔记本类型

1. 新建切片器
2. 字段：`笔记本类型`
3. 标题 →「类型筛选」

### 验证联动

点切片器里选「联想」，看板上所有图表会自动只显示联想的数据。再点「游戏本」，所有图表进一步过滤。这就是交互式看板的核心价值。

## 第六步：美化排版（15 分钟）

### 6.1 页面标题

1. 点击顶部菜单「插入」→「文本框」
2. 输入「淘宝笔记本电脑市场分析看板」
3. 字号 18pt，加粗，深蓝色（#2B579A）
4. 拖到页面顶部居中

### 6.2 布局排列

按以下布局排列所有元素：

```
+----------------------------------------------------------+
|                    页面标题（文本框）                       |
+----------+-----------+-----------+-----------+-----------+
|          |  KPI卡片1  |  KPI卡片2  |  KPI卡片3  |  KPI卡片4  |
|  切片器   +-----------+-----------+-----------+-----------+
|  面板    |  价格区间   |  价格区间   |  类型销量   |
|  (左侧)  |  商品数量   |  销量分布   |  分布饼图   |
|          +-----------+-----------+-----------+
|          |  品牌Top15             |  产地Top10           |
|          +-----------------------+----------------------+
|          |          词云（消费者关注热点）                   |
+----------+------------------------------------------------+
```

### 6.3 主题配色

1. 顶部菜单「视图」→「主题」→ 选「默认」或自选一个浅色主题
2. 统一所有图表的标题字号为 12pt
3. 统一数据标签字号为 9-10pt
4. 图表背景保持白色，页面背景设浅灰色

### 6.4 调整画布大小

1. 顶部菜单「视图」→「页面大小」
2. 类型选「自定义」
3. 宽度 1280，高度 800（16:10 比例适合展示）

## 常见问题

### Q: 词云不显示中文？
A: 在词云格式设置里找到「字体」，改成「微软雅黑」或「SimHei」。

### Q: 饼图显示太多「其他类型」？
A: 在筛选器里把 `笔记本类型` 的「其他类型」取消勾选，只保留游戏本/轻薄本/二合一。

### Q: 条形图排序不对？
A: 点图表右上角的「...」→「排序依据」→ 选你要排序的字段 → 再点切换升序/降序。

### Q: 切片器选了之后图表变空白？
A: 说明该筛选条件下没有数据，正常现象。点切片器右上角的「清除选择」橡皮擦图标恢复。

### Q: 价格区间排序是乱的？
A: 在「数据视图」里，给「价格区间」列设置「按列排序」→ 选一个排序列。或者手动在 Power Query 里设置排序顺序。
